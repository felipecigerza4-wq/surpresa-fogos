# 📝 To-Do List Application

Uma aplicação de lista de tarefas elegante e funcional com armazenamento local (localStorage).

## ✨ Recursos

- ✅ **Adicionar tarefas** - Crie novas tarefas facilmente
- ✔️ **Marcar como concluído** - Clique no checkbox para marcar tarefas
- 🗑️ **Deletar tarefas** - Remova tarefas individuais ou todas as concluídas
- 🔍 **Filtrar tarefas** - Visualize todas, apenas ativas ou apenas concluídas
- 💾 **Local Storage** - Suas tarefas são salvas automaticamente
- 📊 **Estatísticas** - Veja total, concluídas e pendentes em tempo real
- 📥 **Exportar dados** - Baixe suas tarefas em formato JSON
- 📱 **Responsivo** - Funciona perfeitamente em dispositivos móveis
- 🎨 **Design moderno** - Interface elegante com animações suaves

## 🚀 Como usar

1. Abra o arquivo `todo.html` em seu navegador
2. Digite uma tarefa e pressione Enter ou clique em "Adicionar"
3. Clique no checkbox para marcar como concluído
4. Clique no ícone 🗑️ para deletar uma tarefa
5. Use os filtros para visualizar diferentes grupos de tarefas
6. Exporte suas tarefas clicando em "📥 Exportar"

## 💾 Armazenamento

Todas as tarefas são armazenadas no **localStorage** do navegador, o que significa:
- ✅ Suas tarefas são preservadas mesmo após fechar o navegador
- ✅ Nenhum servidor necessário
- ✅ Privacidade completa - dados armazenados localmente

## 📊 Funcionalidades

### Filtros
- **Todas** - Mostra todas as tarefas
- **Ativas** - Mostra apenas tarefas não concluídas
- **Concluídas** - Mostra apenas tarefas marcadas como concluídas

### Ações
- **Limpar Concluídas** - Remove todas as tarefas marcadas como concluídas
- **Exportar** - Baixa um arquivo JSON com todas as suas tarefas
